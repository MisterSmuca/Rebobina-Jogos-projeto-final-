# Rebobina — Landing Page React

Projeto da atividade individual de Desenvolvimento Frontend II.

## Tecnologias

- React
- Vite
- Bootstrap
- Bootstrap Icons
- CSS

## Estrutura

- `Hero`: apresentação da Rebobina.
- `Jogos`: catálogo principal de jogos retrô.
- `Sobre`: história e participação no projeto.
- `ChamadaFinal`: chamada final.
- `Navbar` e `Footer`: elementos compartilhados.

## Destaque da atividade

Os jogos são armazenados em um array e renderizados com `map()` no componente `Jogos.jsx`.

## Como executar

```bash
npm install
npm run dev
```

Para testar a build:

```bash
npm run build
npm run preview
```

## Imagens

As imagens originais da página de Jogos devem ser colocadas em:

```text
public/img/jogos/
```

E o favicon em:

```text
public/img/avanco-rapido.png
```
